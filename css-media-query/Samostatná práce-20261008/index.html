Polévky

České polévky jsou základem tradiční kuchyně. Mezi nejoblíbenější patří bramboračka, která je plná zeleniny a hub, a kulajda, která je krémová polévka s koprem a vejcem.

Další oblíbenou polévkou je česnečka, která je ideální pro chladné zimní večery. Je připravena z česneku, brambor a často se podává s krutony.

Hlavní Jídla

Hlavní jídla české kuchyně jsou často vydatná a sytá. Svíčková na smetaně je jedním z nejznámějších pokrmů, připravuje se z hovězího masa a podává se s houskovým knedlíkem a brusinkami.

Dalším klasickým jídlem je vepřo knedlo zelo, což je vepřové maso s knedlíky a kysaným zelím. Toto jídlo je velmi oblíbené a často se podává při slavnostních příležitostech.

Dezerty

České dezerty jsou sladkou tečkou na závěr jídla. Koláče jsou tradiční pečivo plněné různými náplněmi, jako jsou tvaroh, mák nebo povidla.

Trdelník je další oblíbený dezert, který se často prodává na trzích. Je to sladké pečivo, které se peče na otevřeném ohni a posypává se cukrem a skořicí.
